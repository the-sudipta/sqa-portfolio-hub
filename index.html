How I test

The same steps in every project, from the first question to the last report.

  1. Requirement analysis

    List what the system must do and ask about anything unclear.

  2. Test plan

    Scope, approach, environments, entry and exit criteria, risks.

  3. Test design

    Scenarios and cases with formal techniques, traced to requirements.

  4. Execution

    Run the cases, record honest results, explore around the edges.

  5. Bug reporting

    Reproduce twice, then report with steps, evidence, severity and priority.

  6. Regression

    Automate the stable checks and re-run them on every change.

  7. Report

    Summarise results, risks and a clear release recommendation.
